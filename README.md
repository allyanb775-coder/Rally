# Rally — منصة لاعبي البادل

منصة تجمع لاعبي البادل في منطقة القصيم: تلقى مباراة بمستواك، تكمّل الناقصين، وتشارك في البطولات.

## الفكرة
- **المباريات المفتوحة**: أي لاعب يفتح مباراة، والباقين ينضمون لين يكتمل العدد ٤
- **مستوى اللاعب من ٠ إلى ٧**: يبدأ باستبيان قصير، ويتعدل بعد كل مباراة تنافسية
- **«العب الحين»**: ضغطة وحدة تجيب لك أنسب مباراة لمستواك
- **البطولات**: بطولات دور ١٦، وليالي أمريكانو، وترتيب شهري
- **بطاقة لاعب** بستايل فيفا تتشارك ستوري

## التصميم
ملف Figma (صفحة V2): https://www.figma.com/design/fltxgRacc2sZ3idI6VDHo5

## التقنيات المخططة
- **Expo (React Native)**: تطبيق واحد للآيفون والأندرويد والويب
- **Supabase**: قاعدة البيانات وتسجيل الدخول
- رسائل التحقق برقم الجوال عن طريق مزود سعودي (Unifonic أو Taqnyat)

## الحالة
التطبيق في `app/` (Expo SDK 58 + Expo Router). إذا انحطت قيم Supabase في `app/.env` (شوف `.env.example`) يشتغل على قاعدة البيانات مع تسجيل دخول برقم الجوال، وإذا ما انحطت يشتغل على بيانات تجريبية.
مخطط قاعدة البيانات وقواعد الحماية في `supabase/migrations/`.

## التشغيل
```bash
cd app
npm install
npm run web        # أو: npx expo start
npm test           # اختبارات منطق المستوى و«العب الحين»
npm run typecheck
```
